# My Project : Fitness Log
 A modern fitness workout management app where users can explore exercises, view detailed workout information, create a daily workout plan, and save exercises for later.
 

 ## Technologies I have Used :
 - **Next.js** – React framework for building the application .

 - **TypeScript** – Type-safe and maintainable code

 - **Tailwind CSS** – Responsive and utility-first styling

 - **daisyUI** – Ready-to-use UI components

 ## 5 key features of my project :

 ### 1. Exercise Library –
 Browse exercises with images, muscle groups, equipment, duration, calories, and ratings.

 

 ### 2. Exercise Details –
  View complete exercise information and add exercises directly to your daily plan or save them for later.



 ### 3. My Today's Plan – 
 Manage selected exercises and view total exercises, workout time, and calories.

 ### 4. Saved Exercises – 
 Save favorite exercises and access them anytime from the Saved tab.

 ### 5. Sorting & Management – 
 Sort exercises by duration, rating, or calories and remove exercises from your plans easily.
